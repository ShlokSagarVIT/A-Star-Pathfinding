# A-Star-Pathfinding
This project implements the A* algorithm to find the shortest path in a grid with obstacles. It uses heuristic-based search (Manhattan distance) to efficiently reach the goal. The project demonstrates practical AI pathfinding used in navigation, robotics, and games.
# A* Pathfinding Algorithm Project

## 📌 Description

This project implements the A* search algorithm to find the shortest path between two points on a grid.

## 🚀 Features

* Finds optimal path
* Handles obstacles
* Uses Manhattan heuristic

## ▶️ How to Run

1. Install Python
2. Run: python main.py

## 🧠 Algorithm Used

A* Search (Informed Search Algorithm)

## 📊 Example

Start: (0,0)
End: (4,4)

## 📚 Learning Outcome

* Understanding of informed search
* Heuristic-based optimization
